# PCB Design with KiCad

## 🎯 Objective

Learn the fundamental concepts of KiCad software for designing simple and double-sided PCBs, including schematic capture, footprint association, and PCB routing.

## 🧰 Software Used

- **KiCad** (Free, open-source EDA software)
- Available at: https://www.kicad.org/
- Documentation: https://docs.kicad.org/

## 📋 Project Structure

### Part 1: Project Creation

Create a new project in KiCad and launch the Schematic Editor.

### Part 2: Schematic Design

**Role of the Schematic:** The schematic is the blueprint of the electronic circuit. It shows the logical connections between components (how they are electrically connected) without worrying about physical layout. It helps to understand the circuit functionality and is the first step before PCB design.

Draw the circuit schematic (CNY70 sensor with pull-up resistor, powered by 5V).

**Components:**
- CNY70 sensor
- Resistors
- Power supply (5V)
- GND
